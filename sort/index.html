SORT and SORTN functions in Google Sheets

SORT returns a range in sorted order; SORTN returns only the first few rows after sorting.

SORT gives you a sorted copy of your data that re-sorts itself when the data changes. The original stays in the order it was entered. SORTN goes one step further and returns only the top few rows, which makes "top five" lists a one-formula job.

Syntax

=SORT(range, sort_column, is_ascending, [sort_column2, is_ascending2], ...)
=SORTN(range, [n], [display_ties_mode], [sort_column, is_ascending], ...)
ArgumentWhat it is
rangeThe data to sort.
sort_columnThe number of the column to sort by, counted from the left of the range, or a separate range of the same height.
is_ascendingTRUE for A to Z and smallest first. FALSE for the reverse.
nFor SORTN: how many rows to return.
display_ties_modeFor SORTN: 0 returns exactly n rows. 1 also returns rows that tie with the last one. 2 removes duplicate rows first. 3 returns n distinct rows with their duplicates.

Examples

  • =SORT(B2:D8,3,FALSE)
    Result:
    Power BankElectronics1299
    Basmati Rice 5 kgGrocery650
    Steel BottleHome450
    Toor Dal 1 kgGrocery160
    LED BulbElectronics110
    NotebookStationery60
    Ball PenStationery10

    By the 3rd column of the range, the price, largest first.

  • =SORT(B2:C8,2,TRUE,1,TRUE)
    Result:
    LED BulbElectronics
    Power BankElectronics
    Basmati Rice 5 kgGrocery
    Toor Dal 1 kgGrocery
    Steel BottleHome
    Ball PenStationery
    NotebookStationery

    Two levels: by category, then by item name.

  • =SORT(B2:B8,E2:E8,FALSE)
    Result:
    Notebook
    LED Bulb
    Toor Dal 1 kg
    Steel Bottle
    Basmati Rice 5 kg
    Power Bank
    Ball Pen

    The sort column can be a range outside the data: names in order of stock, largest first.

  • =SORTN(B2:D8,3,0,3,FALSE)
    Result:
    Power BankElectronics1299
    Basmati Rice 5 kgGrocery650
    Steel BottleHome450

    SORTN: the top 3 by price.

  • =SORTN(B2:D8,2,0,3,TRUE)
    Result:
    Ball PenStationery10
    NotebookStationery60

    The two cheapest items.

  • =SORT(UNIQUE(C2:C8))
    Result:
    Electronics
    Grocery
    Home
    Stationery

    With only a range, SORT sorts by the first column, ascending.

How SORT works

After the range, arguments come in pairs: which column to sort by, and TRUE for ascending or FALSE for descending. Add more pairs for further levels. The second example sorts by category and, inside each category, by name.

The sort column can be given in two ways.

  • A number: the position of the column inside the range. 1 is its first column.
  • A range: any column of the same height, even one that is not part of what you are returning. The third example lists names in order of stock without showing the stock.

With the range alone and nothing else, SORT uses the first column, ascending.

SORTN: the first n rows

SORTN sorts and then keeps only the first n rows. =SORTN(B2:D8, 3, 0, 3, FALSE) reads: from this range, return 3 rows, with tie mode 0, sorted by column 3 descending.

The third argument decides what happens with ties and duplicates.

ModeReturns
0exactly n rows
1n rows, plus any further rows that tie with the nth
2n rows after removing duplicate rows
3n distinct rows, along with all their duplicates

Mode 1 is the fair one for a prize list: if two people share third place, both appear.

A sorted, filtered list

SORT wraps naturally around FILTER: =SORT(FILTER(A2:F13, C2:C13="North"), 6, FALSE) shows the North sales, largest first. Remember that the column number then counts inside the filtered result.

A custom order

To sort by your own order, such as Small, Medium, Large, give SORT the position of each value in that list: =SORT(A2:C20, MATCH(B2:B20, {"Small";"Medium";"Large"}, 0), TRUE).

Sorting in random order

=SORT(A2:A20, RANDARRAY(19), TRUE) shuffles a list of nineteen names. It reshuffles whenever the sheet recalculates, so copy the result and paste it as values to keep one order.

Things to know

  • Leave the heading row out of the range, or it is sorted in with the data.
  • Text sorts without regard to capital letters. Numbers stored as text sort as text, so "100" comes before "20".
  • The result occupies the cells below and beside the formula. Typing into them gives #REF!.
  • The result cannot be edited. Change the source data.

SORT, the menu, or QUERY?

  • Data, Sort range rearranges the real data, once.
  • SORT builds a live sorted copy.
  • QUERY with order by sorts and can filter and total in the same formula.

Common mistakes

  • TRUE and FALSE the wrong way round. FALSE is descending.
  • A column number counted from column A of the sheet, not from the start of the range.
  • Expecting SORT to change the original data.
  • A sort range of a different height from the data.

In Excel

Excel's SORT is =SORT(array, sort_index, sort_order), where the order is 1 or -1 instead of TRUE or FALSE, and several levels are given as lists in curly brackets. Sorting by an outside range is a separate function there, SORTBY. Excel has no SORTN.
