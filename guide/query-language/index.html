The QUERY language, clause by clause

The QUERY function takes an instruction written in a small language of its own. This guide goes through that language one clause at a time, using one sample table. If you have used SQL, most of it will look familiar. If you have not, each clause is a plain English word that does what it says.

The data is A1:F13. In a query, columns are named by their letters: A is the date, B the salesperson, C the region, D the product, E the units and F the amount. The final argument, 1, tells QUERY that the first row is a heading.

The order of the clauses

Clauses must be written in this order. Leave out any you do not need.

select · where · group by · pivot · order by · limit · offset · label · format

select: which columns

  • =QUERY(A1:F13,"select B, F limit 3",1)
    Result:
    SalespersonAmount
    Asha1200
    Ravi500
    Meena3000

    Two columns, in the order asked for.

select * returns all columns and is the same as leaving select out. A column can also be calculated, as in select B, F*2. Sheets then writes a heading of its own for it, which you will want to replace with label.

where: which rows

  • =QUERY(A1:F13,"select B, F where F >= 2400",1)
    Result:
    SalespersonAmount
    Meena3000
    Meena2400
    Asha3750

    A number condition. Rows stay in their original order.

  • =QUERY(A1:F13,"select B, D where C = 'East'",1)
    Result:
    SalespersonProduct
    AshaPen
    MeenaNotebook
    RaviNotebook

    Text in single quotation marks.

  • =QUERY(A1:F13,"select B, F where D contains 'book' and F > 1000",1)
    Result:
    SalespersonAmount
    Asha1200
    Meena2400
    Ravi1500

    contains, and two conditions joined with and.

  • =QUERY(A1:F13,"select B, A where A >= date '2026-04-01'",1)
    Result:
    SalespersonDate
    Ravi01-Apr-2026
    Meena18-Apr-2026
    Asha06-May-2026

    A date is written as the word date and year-month-day in single quotation marks.

Comparison words for text: contains, starts with, ends with, matches (a regular expression for the whole value) and like (with % for any run of characters). Use is null and is not null for empty cells, and not to reverse a condition. Text comparisons are case sensitive. Wrap the column in lower() to ignore case: where lower(C) = 'east'.

group by: totals for each value

  • =QUERY(A1:F13,"select C, sum(F), count(F) group by C",1)
    Result:
    Regionsum Amountcount Amount
    East42003
    North87505
    South57504

    One row per region, with a total and a count.

  • =QUERY(A1:F13,"select B, max(F), min(F) group by B",1)
    Result:
    Salespersonmax Amountmin Amount
    Asha3750300
    Kabir900600
    Meena3000800
    Ravi1500500

    Largest and smallest sale of each person.

The totalling functions are sum, count, avg, max and min. Every column in the select must be either in the group by or inside one of them.

pivot: values across the top

pivot turns the values of a column into column headings. This makes a cross table.

  • =QUERY(A1:F13,"select C, sum(F) group by C pivot D",1)
    Result:
    RegionBagNotebookPen
    East3900300
    North67501200800
    South37509001100

    Regions down the side, products across the top, totals in the grid. East sold no bags, so that cell is empty.

order by, limit and offset

  • =QUERY(A1:F13,"select B, F order by F desc limit 3",1)
    Result:
    SalespersonAmount
    Asha3750
    Meena3000
    Meena2400

    Largest first, top three.

  • =QUERY(A1:F13,"select B, F order by F desc limit 2 offset 3",1)
    Result:
    SalespersonAmount
    Asha2250
    Ravi1500

    Skip the first three, then take two.

  • =QUERY(A1:F13,"select C, sum(F) group by C order by sum(F) desc",1)
    Result:
    Regionsum Amount
    North8750
    South5750
    East4200

    Sorting groups by their total.

asc is the default. List several columns for several sort levels: order by C, F desc.

label and format

  • =QUERY(A1:F13,"select C, sum(F) group by C label C 'Area', sum(F) 'Total sales'",1)
    Result:
    AreaTotal sales
    East4200
    North8750
    South5750

    label renames headings.

  • =QUERY(A1:F13,"select C, sum(F) group by C label sum(F) ''",1)
    Result:
    Region
    East4200
    North8750
    South5750

    An empty label removes a heading.

format sets how a column is shown: format F '#,##0.00', A 'dd-mmm-yyyy'. To drop the heading row from a result altogether, set every label to empty or wrap the query in QUERY(..., 0) over data without headings.

Dates: year, month and friends

Scalar functions work on date columns: year(A), month(A), day(A), dayOfWeek(A), quarter(A). One trap: month() counts from 0, so January is 0 and December is 11. Add 1 to get the usual number: select month(A)+1, sum(F) group by month(A)+1.

Using cell values in a query

The query is text, so join cell values into it with &.

  • Text needs single quotation marks around it: "select B, F where C = '"&H1&"'"
  • A number does not: "select B, F where F > "&H2
  • A date must be formatted: "where A >= date '"&TEXT(H3,"yyyy-mm-dd")&"'"

Build long queries in a spare cell first, as ordinary text, and look at the result. A missing space or quotation mark is easy to see there.

Data without column letters

When the data comes from IMPORTRANGE, from curly brackets, or from another function, it has no letters. Name the columns Col1, Col2, Col3, counting from the left: =QUERY(IMPORTRANGE(url,"Sales!A:F"), "select Col2, sum(Col6) group by Col2", 1).

Curly brackets stack ranges for QUERY: {Jan!A2:F; Feb!A2:F} puts two tabs one above the other.

Things that go wrong

Message or symptomLikely cause
#VALUE!, unable to parse query stringa spelling slip, a clause out of order, or double quotation marks inside the query
#VALUE!, no columna letter outside the data range, or letters used where Col1 is needed
values missing from a columnthe column mixes numbers and text; the minority type is treated as empty
headings joined into one row of textthe headers argument was left out and guessed wrongly; give it as 1
nothing returneda text condition with the wrong case, or stray spaces in the data
