Google Sheets formulas cheat sheet

The syntax of every function on this site on one page, with QUERY clauses and regular-expression symbols at the top. Tap a function for its page. Arguments in square brackets are optional.

How to read this sheet

Each line in the function tables shows a function as Sheets' own help box shows it: the name, then the arguments in order. Square brackets mark an argument you may leave out. Three dots mean more of the same may follow. The sheet is a reminder for people who have met the function already. If a line is not clear, tap the name and read its page, which shows the function at work on a sample sheet.

If your spreadsheet's locale uses a comma as the decimal mark, read every comma between arguments as a semicolon.

Regular expression symbols

SymbolMatches

Only in Sheets

=QUERY(data, query, [headers])QUERY selects, filters, sorts and summarises a range using a short query written in words, much like SQL
=ARRAYFORMULA(array_formula)ARRAYFORMULA makes an ordinary formula work on a whole range at once, filling a column from a single cell
=IMPORTRANGE(spreadsheet_url, range_string)IMPORTRANGE brings a range of cells from another Google Sheets file into this one, and keeps it up to date
=FILTER(range, condition1, [condition2], ...)FILTER returns the rows of a range that meet one or more conditions
=SORT(range, sort_column, is_ascending, [sort_column2, is_ascending2], ...)SORT returns a range in sorted order; SORTN returns only the first few rows after sorting
=SORTN(range, [n], [display_ties_mode], [sort_column, is_ascending], ...)SORT returns a range in sorted order; SORTN returns only the first few rows after sorting
=UNIQUE(range, [by_column], [exactly_once])UNIQUE returns each different value in a range once; COUNTUNIQUE counts how many different values there are
=COUNTUNIQUE(value1, [value2], ...)UNIQUE returns each different value in a range once; COUNTUNIQUE counts how many different values there are
=SPLIT(text, delimiter, [split_by_each], [remove_empty_text])SPLIT divides a text into separate cells at a chosen character; JOIN puts the values of a range together with a separator
=JOIN(delimiter, value_or_array1, [value_or_array2], ...)SPLIT divides a text into separate cells at a chosen character; JOIN puts the values of a range together with a separator
=FLATTEN(range1, [range2], ...)FLATTEN turns a block of cells, or several ranges, into a single column
=SPARKLINE(data, [options])SPARKLINE draws a tiny chart inside a single cell from a range of numbers

Lookup

=VLOOKUP(search_key, range, index, [is_sorted])VLOOKUP finds a value in the first column of a range and returns a value from the same row in another column
=XLOOKUP(search_key, lookup_range, result_range, [missing_value], [match_mode], [search_mode])XLOOKUP finds a value in one range and returns the matching item from another, in any direction
