Google Sheets functions, explained with worked examples

The functions that make Google Sheets different, and the everyday ones explained the Sheets way. Each page has the syntax, worked examples on a small sample sheet, the mistakes people make, and how Excel differs. Free, no login.

Only in Sheets

  • QUERYQUERY selects, filters, sorts and summarises a range using a short query written in words, much like SQL
  • ARRAYFORMULAARRAYFORMULA makes an ordinary formula work on a whole range at once, filling a column from a single cell
  • IMPORTRANGEIMPORTRANGE brings a range of cells from another Google Sheets file into this one, and keeps it up to date
  • FILTERFILTER returns the rows of a range that meet one or more conditions
  • SORT and SORTNSORT returns a range in sorted order; SORTN returns only the first few rows after sorting
  • UNIQUE and COUNTUNIQUEUNIQUE returns each different value in a range once; COUNTUNIQUE counts how many different values there are
  • SPLIT and JOINSPLIT divides a text into separate cells at a chosen character; JOIN puts the values of a range together with a separator
  • FLATTENFLATTEN turns a block of cells, or several ranges, into a single column
  • SPARKLINESPARKLINE draws a tiny chart inside a single cell from a range of numbers

Lookup

  • VLOOKUPVLOOKUP finds a value in the first column of a range and returns a value from the same row in another column
  • XLOOKUPXLOOKUP finds a value in one range and returns the matching item from another, in any direction
  • INDEX and MATCHINDEX returns the cell at a position in a range and MATCH finds the position of a value; together they make a flexible lookup

Logical

  • IF and IFSIF returns one value when a condition is true and another when it is false; IFS checks several conditions in turn
  • IFERROR and IFNAIFERROR returns a value of your choice when a formula gives an error; IFNA does so only for the #N/A error

Math and counting

  • SUMIF and SUMIFSSUMIF adds the cells that meet one condition; SUMIFS adds the cells that meet several
  • COUNTIF and COUNTIFSCOUNTIF counts the cells that meet one condition; COUNTIFS counts the rows that meet several

Text

  • REGEXMATCHREGEXMATCH tests whether a text matches a pattern and returns TRUE or FALSE
  • REGEXEXTRACTREGEXEXTRACT pulls out the part of a text that matches a pattern
  • REGEXREPLACEREGEXREPLACE replaces every part of a text that matches a pattern with other text
  • ISEMAIL, ISURL and ISDATEISEMAIL, ISURL and ISDATE test whether a value has the form of an email address, a web address or a date
  • TEXTTEXT turns a number or a date into text in the format you choose
  • TEXTJOIN, CONCATENATE and CONCATTEXTJOIN joins values with a separator and can skip empty cells; CONCATENATE and the & sign join values end to end

Date and time

  • DATEDIFDATEDIF returns the number of complete years, months or days between two dates

Web and import

  • GOOGLEFINANCEGOOGLEFINANCE fetches current or past prices of shares and currencies from Google Finance
  • GOOGLETRANSLATE and DETECTLANGUAGEGOOGLETRANSLATE translates text from one language into another; DETECTLANGUAGE reports which language a text is in
  • IMAGEIMAGE shows a picture from a web address inside a cell
  • IMPORTHTML, IMPORTXML and IMPORTDATAIMPORTHTML brings a table or list from a web page into the sheet; IMPORTXML and IMPORTDATA fetch other kinds of web data

Start with what only Sheets has

Most spreadsheet help treats Google Sheets as a copy of Excel. It is not. A handful of functions exist only here, and they change how you build a sheet.

  • QUERY picks columns, filters rows, sorts and totals in one formula. The QUERY language guide goes through it clause by clause.
  • ARRAYFORMULA lets one formula fill a whole column, including rows added later.
  • IMPORTRANGE reads data from another spreadsheet file.
  • SPLIT and the three REGEX functions, REGEXMATCH, REGEXEXTRACT and REGEXREPLACE, take text apart and clean it.
  • GOOGLEFINANCE, GOOGLETRANSLATE, IMPORTHTML and IMAGE bring in live data from the web.

If you learn QUERY and ARRAYFORMULA, you will write a tenth as many formulas.

Questions people ask

Do Excel formulas work in Google Sheets?

Most do. SUM, IF, VLOOKUP, COUNTIFS and the text and date functions are shared. The guide Google Sheets and Excel: where formulas differ lists what is different.

Why does my formula use semicolons?

The character between arguments follows the spreadsheet's locale, under File, Settings. Where a comma is the decimal mark, Sheets uses a semicolon. Replace the commas in our formulas with semicolons.

Why do I get #REF! from a formula that looks right?

Usually because a formula that returns many cells, such as FILTER or ARRAYFORMULA, has something in its way. Clear the cells below and beside it. More in the errors guide.

Is Google Sheets free?

It is free to use with a personal Google account. Organisations may use it through a paid Google Workspace plan. For current plans and limits, see Google's own pages.
