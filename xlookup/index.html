Lookup

XLOOKUP function in Google Sheets

XLOOKUP finds a value in one range and returns the matching item from another, in any direction.

XLOOKUP is the newer lookup function, added to Google Sheets in 2022. It does what VLOOKUP does with fewer traps: exact match by default, any direction, and a built-in answer for a missing value.

Syntax

=XLOOKUP(search_key, lookup_range, result_range, [missing_value], [match_mode], [search_mode])
ArgumentWhat it is
search_keyThe value to look for.
lookup_rangeThe single row or column to search.
result_rangeThe row or column to return from, the same size as the lookup range.
missing_valueWhat to show if nothing is found. Without it the result is #N/A.
match_mode0 exact (the default), 1 exact or next larger, -1 exact or next smaller, 2 wildcard.
search_mode1 from the first item (the default), -1 from the last.

Examples

  • =XLOOKUP("C301",A2:A8,B2:B8)
    Result: LED Bulb

    Search the codes, return the item. Exact match is the default.

  • =XLOOKUP("Notebook",B2:B8,A2:A8)
    Result: B201

    A lookup to the left: search the names, return the code.

  • =XLOOKUP("Z999",A2:A8,B2:B8,"Not found")
    Result: Not found

    The fourth argument is the message for a missing key.

  • =XLOOKUP("D401",A2:A8,D2:E8)
    Result:
    45055

    A result range two columns wide returns two cells.

  • =XLOOKUP(500,D2:D8,B2:B8,,-1)
    Result: Steel Bottle

    Match mode -1: no price is exactly 500, so the next smaller one, 450, is used.

  • =XLOOKUP("Asha",B2:B13,F2:F13,,0,-1)
    Result: 3750

    Search mode -1 starts from the bottom: Asha's most recent sale.

How it works

XLOOKUP takes two separate ranges: one to search, one to answer from. It finds the position of the key in the first and returns the item at the same position in the second. There is no column number, and it does not matter which range is on the left.

Match and search modes

Match mode -1 returns the next smaller item when there is no exact match, and 1 the next larger. Unlike VLOOKUP's sorted mode, the data need not be sorted. Mode 2 allows the wildcards * and ?.

Search mode -1 searches from the last item upwards, which returns the latest entry in a list kept in date order, as the last example shows.

Returning a whole row

If the result range is several columns wide, XLOOKUP returns the whole row of results across the cells to the right. One formula can bring back the name, the category and the price for a code.

Across a whole column

Unlike VLOOKUP, XLOOKUP is awkward to expand with ARRAYFORMULA when it must return one value per row for a column of keys. It works in simple cases, =ARRAYFORMULA(XLOOKUP(A2:A10, Codes, Names)), but if you need a self-filling column, VLOOKUP inside ARRAYFORMULA is the well-trodden path.

When to use which

  • New sheets, used only in Google Sheets or in modern Excel: XLOOKUP.
  • Sheets that will be downloaded as Excel files for people on Excel 2019 or earlier: VLOOKUP or INDEX and MATCH, since XLOOKUP shows #NAME? there.
  • Every matching row, not just the first: FILTER.

Common mistakes

  • Lookup and result ranges of different sizes, which gives an error.
  • Skipping an optional argument without its comma. To set match mode but no missing value, write ,,-1.
  • Numbers on one side and text digits on the other.
  • Expecting more than the first match.

In Excel

XLOOKUP exists in Excel 2021 and Microsoft 365 with the same six arguments, under slightly different names. Formulas carry over unchanged.
