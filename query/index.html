QUERY function in Google Sheets

QUERY selects, filters, sorts and summarises a range using a short query written in words, much like SQL.

QUERY is the most powerful function in Google Sheets, and Excel has nothing quite like it. One formula can pick columns, keep only some rows, sort them, and work out totals for each group. It replaces a combination of FILTER, SORT, SUMIF and a pivot table.

Syntax

=QUERY(data, query, [headers])
ArgumentWhat it is
dataThe range to work on, such as A1:F13. Include the heading row.
queryThe instruction, as text in double quotation marks. Columns are named by their letters.
headersHow many rows at the top are headings. Usually 1. If left out, Sheets guesses.

Examples

  • =QUERY(A1:F13,"select B, F where F > 2000 order by F desc",1)
    Result:
    SalespersonAmount
    Asha3750
    Meena3000
    Meena2400
    Asha2250

    Two columns, only the rows with an amount above 2000, largest first. The headings come along.

  • =QUERY(A1:F13,"select B, sum(F) group by B",1)
    Result:
    Salespersonsum Amount
    Asha7500
    Kabir1500
    Meena6200
    Ravi3500

    A total for each salesperson. Groups come out in alphabetical order.

  • =QUERY(A1:F13,"select C, sum(F) group by C order by sum(F) desc label sum(F) 'Total'",1)
    Result:
    RegionTotal
    North8750
    South5750
    East4200

    Totals by region, largest first, with the heading renamed by label.

  • =QUERY(A1:F13,"select D, count(A) group by D",1)
    Result:
    Productcount Date
    Bag4
    Notebook4
    Pen4

    How many sales of each product.

  • =QUERY(A1:F13,"select B, D, F where C = 'North' and D = 'Bag'",1)
    Result:
    SalespersonProductAmount
    MeenaBag3000
    RaviBag1500
    AshaBag2250

    Two conditions joined with and. Text inside the query goes in single quotation marks.

  • =QUERY(A1:F13,"select B, F order by F desc limit 3",1)
    Result:
    SalespersonAmount
    Asha3750
    Meena3000
    Meena2400

    The three largest sales.

How it works

You hand QUERY a range and an instruction written as text. The instruction uses a small language of its own, the Google Visualization API Query Language, which reads like SQL. Columns are called by their letters: A, B, C.

The result spills into the cells below and to the right of the formula, with the headings on top.

The parts of a query

They must appear in this order. All are optional except that you need at least one.

ClauseDoesExample
selectwhich columns to returnselect B, F
wherewhich rows to keepwhere F > 2000
group byone row per value, with totalsgroup by B
order bysortingorder by F desc
limitonly the first rowslimit 3
labelrename a headinglabel sum(F) 'Total'

select * returns every column.

Conditions in where

  • Numbers are written plainly: where F > 2000.
  • Text goes in single quotation marks, because the whole query is already inside double ones: where C = 'North'.
  • Join conditions with and and or.
  • For part of a text, use contains, starts with or ends with: where D contains 'book'.
  • Text comparisons are case sensitive. 'north' does not match North.
  • Empty cells: where B is not null.

Totals: sum, count, avg, max, min

With group by, every column in the select must either be grouped or sit inside one of the totalling functions. select B, sum(F) group by B gives one row per salesperson. The heading of a total column reads like "sum Amount". Use label to give it a better name.

Using a value from a cell

The query is text, so a cell's value has to be joined into it. With a region typed in H1:

=QUERY(A1:F13, "select B, F where C = '"&H1&"'", 1)

Note the single quotation marks either side of the join. For a number, leave them out: "where F > "&H1.

Dates

A date in a query must be written as date '2026-03-01': the word date, then year-month-day in single quotation marks. To use a date from a cell, format it with TEXT: "where A >= date '"&TEXT(H1,"yyyy-mm-dd")&"'".

Each column must hold one kind of data

QUERY decides the type of each column from most of its values, and treats the minority as empty. A column that is mostly numbers with a few text entries loses the text entries. This is the usual reason for values going missing from a QUERY result. Keep each column to one type.

Common mistakes

  • Double quotation marks inside the query. Use single ones.
  • Column names instead of letters. select Amount does not work.
  • Clauses in the wrong order, such as order by before where.
  • #VALUE! with a message about parsing: a spelling slip in the query text.
  • A mixed-type column silently dropping values.

In Excel

Excel has no QUERY function. The nearest tools there are FILTER and SORT for rows, PivotTables for totals, and Power Query for bigger jobs. A sheet that uses QUERY shows only its last values after being saved as an Excel file.
